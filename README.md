# 麻将计分器（广东玩法）

四人广东麻将实时计分工具：选牌型自动算倍数、庄家买马、一局合并结算、📊 统计表汇总。

- **在线使用**：<https://ttonger98.github.io/mahjong-scorer/>
- 纯前端单文件，**无网络请求、无依赖**，数据存在本机 `localStorage`。
- 手机端可直接安装/添加到主屏幕当 App 用（安卓 Chrome 选“安装应用”，iPhone Safari 选“添加到主屏幕”），支持离线打开；线上更新自动热更，无需重装。已适配各机型、禁用双击页面缩放。

## 功能

- **牌型自动算倍数**：28 种牌型多选，倍数按加法叠加（无牌型＝平胡 1 倍）；可设置“胡牌倍数上限”；海底捞月＋3。
- **胡牌方式**：自摸（三家各付）／吃胡（被吃胡者只付自己一份，另两家不付）／抢杠（被抢者包三家）／杠爆（放杠者包三家）；支持**一炮多响**——同一放炮者被多人同时吃胡/抢杠，可连续添加多条胡牌记录，各自按自己的倍数结算。
- **杠（固定）**：暗杠＝底分×1（三家各付）／明杠＝底分×1.5（点杠人付）／加杠＝底分×0.5（三家各付）。
- **庄家买马**：在“本局牌况”统一选“中马情况”（杠/胡牌弹窗不再重复选），同一人可中多匹、按马数乘；结算时马同时作用于胡牌（中胡牌者/中输家/中庄家自己）与杠（中杠者/中付家），与杠、胡牌合并一次清算。
- **一局合并结算**：开局后在“本局牌况”里添加杠＋记录胡牌，点“💰 结算本局”把本局杠和胡牌一次清算（无流局）。
- **统计表 📊**：顶部各家所有局总结算，下方每局明细（杠＋胡牌＋各家变化），外加转账明细和分数走势。
- **换庄**：点对局页任意玩家卡片直接把该玩家设为庄家。
- **撤销**：可撤销上一局，分数、局数自动回退。

## 使用流程

1. 开局设置：填玩家名、底分、胡牌倍数上限（0=无上限）→ 开始游戏。
2. 每局结束：在“本局牌况”里「＋添加杠」录入本局杠（可多条），点「记录胡牌」选胡牌方式/牌型/马。
3. 点「💰 结算本局」统一清算，自动换庄。
4. 结束后点右上角「📊」看统计表并复制结算单。
